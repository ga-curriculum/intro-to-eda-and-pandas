## About
An introduction to exploratory data analysis and the `pandas` library.


## Learning Objectives

*You will be able to:*

- Explain the difference between EDA for exploration versus EDA for modeling.
- Define `pandas` `Series` and `DataFrame` types and their uses.
- Understand the benefit of vectorized dataset operations.
- Read in a data set with the `pandas` library.
- Explore the characteristics of a data set at a high level with `pandas`.
